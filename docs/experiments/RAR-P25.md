## Result / disposition

**Fingerprint exact at every engine commit: 7,601,220 / EBF 2.474, 40/40 positions identical.** Tests 284 release / 283 debug at the end (one added: the sink recorder test; one deleted: the `EngineCommand` constructor test, whose flags no longer exist). Diag counters: identical to B.1 except `check_extensions`, `quiet_see_prune`, `skip_quiets_nodes`, deleted. **NPS: final head vs B.1 pool +0.21%, 95% bootstrap [−0.34%, +0.68%]** (base 3,207,944, cand 3,214,726; best-of −0.43%); **T6 alone vs T5 +0.04% [−0.47%, +0.51%]** (3,233,185 vs 3,234,564), so T6 is kept. Retired phase, step and ledger numbers: zero in the owned `src/` files, the repository configuration and the tools (release and tool versions and evidence citations excepted); 316 remain in `eval.rs`, `params.rs`, `node.rs`, `movepick.rs`, `history.rs` and `correction.rs`. `src/` 22,215 → 21,836 lines (−379). **Calibration:** fingerprint and NPS as predicted (the CI's upper bound exceeds +0.5% on the favourable side, the point estimate is inside). Size missed in **magnitude**: rewritten comments replaced prose rather than being deleted, the command enum, keyword table, sink and slot trait added documented lines, and scaffold mechanism comments were left to their clusters. Surface missed in **premise**: 15 public types (`EngineOptions`, `SearchLimits`, `SyzygyOptions`, `PositionState` (since flattened by T4), `File`, `Rank`, the Syzygy probe types, `WacPosition`, `ZobristKeys`, `AttackTables`, `SmallInt`, `Wdl`) are reached by integration tests only through public fields and signatures, so name-based use undercounts them; they stay `pub`. The review's claim that no external file imports a free move generator was false: `benches/board.rs` imported four.

Comment hygiene by rewrite does not shrink a file much; count deletions, not the line total.
