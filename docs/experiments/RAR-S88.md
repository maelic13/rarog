## Experiment and conditions

**B.4.4, the cluster 3 gate — REGISTERED 2026-09-30, before any game; binaries built and hashed.** Candidate: the `b4quiet` arm with RAR-S86's block-1 theta on fourteen coordinates (`QsSeeMargin` 266, `QsSeeClampHi` 208, `QsSeeBadFloor` −43, `QsFutilityMargin` 178, `QsDeltaMargin` 205, `QsCountLimit` 3, `QsStandPatLerp` 565, `QsCutoffLerp` 586, `CoreRfpSquare` 152, `CoreRfpLinear` 15, `CoreRfpConstant` −32, `CoreRazorBase` 295, `CoreRazorSquare` 167, `CoreNmpBase` 168) and `CoreQsEvasionPrune` on by default (RAR-S87), baked by script on a throwaway branch from `dev` at `a29c20c` (recipe `analysis/b43_gate_bake.patch`, fifteen values, nothing else; the branch is deleted). **Binary:** `tools/test_engines/rarog-b43gate-pext-pgo.exe`, sha256 **`B2CE604C1AE17FC6FDB1A4261D0F9B65713928C87DE1D3621D72E709F69F9195`**, `cargo xtask build --arch pext --pgo --features b4quiet`, bench **11,171,726**, equal to `rarog-b43-tune.exe` with the fifteen values set by option. **Baseline:** the accepted head as the off arm of the same source, `rarog-b41off-pext-pgo.exe` (sha256 `3FFB462D…`, 12,897,901, `b734caa`), so no source or build-recipe offset enters. **Gate:** Colosseum `sprt-default`, `[0,3]` nElo, alpha = beta = 0.05, `3+0.03`, 20 ms margin, Hash 64, Threads 1, 14 slots, UHO random, no adjudication, **cap 20,000 pairs**, seed 387, `tools/results/b43-gate`; runner `cli-v0.2.0` pinned; dry run at policy. No fixed match is played beside it (PROCESS, one gate, one read). H1 accepts cluster 3 as a unit: the bake lands on `dev`, `b4quiet` becomes a default feature and the six shared coordinates become the head's; before that commit the allocation guard's precondition is repaired in its own commit (on the baked tree its position 30 grows 7.6× between depth 5 and 13, under the required 10×, with allocations inside the budget). H0 or the cap rejects the cluster as a unit (PLAN rule 6): nothing is baked; the PV-bit repair and evasion pruning may then be re-registered on their own. **Prediction:** RAR-S85's P2 stands unchanged (**+8 ± 8 Elo**, H1 0.55, cap 0.30, H0 0.15); added here: if H1, in under 6,000 pairs (0.5). Parts measured so far, not summed: the unfitted arm +0.7 ± 9.3 over the head, evasion pruning +7.8 ± 9.4 over that arm. Stop rule: bounds, cap, book and adjudication never change; an unresolved cap is a rejection. Maintainer-run: about an hour if the effect is near +8 Elo, about seven hours at the cap.

## Result / disposition

**Played 2026-09-30** (idle host, 0 faults, hashes and fingerprints as registered): **SPRT H1 accepted at 10,705 pairs**, 21,410 games, **+4.4 ± 2.9 Elo** (+7.0 ± 4.7 nElo; 5655-10370-5385, [364, 2515, 4710, 2719, 397]), LLR +2.95. **Cluster 3 accepted as a unit**: the allocation guard's precondition repaired first (`e5f61b5`: bench position 33 replaces 30, which the candidate solves too early to grow), then the recipe baked and `b4quiet` made a default feature in `5a5c150`; the default build reads **11,171,726 / EBF 2.512** (equal to the gate binary), the previous head's search (`--no-default-features --features b3proof`) 14,047,177 / EBF 2.542 on the shared coordinates' fitted values, and the legacy search 7,590,542 / EBF 2.473, no longer 7,601,220, because `QsSeeMargin`, `QsSeeClampHi` and `QsSeeBadFloor` are declared in the parameter set it also reads.

## Conditional lesson

**Calibration:** P2 predicted +8 ± 8 Elo with H1 at 0.55: hit, in the interval's lower half. "Under 6,000 pairs" (0.5): missed, 10,705; the estimate read −0.3 ± 5.9 at 2,634 pairs and +3.8 ± 3.1 at 9,092, a reminder that a partial SPRT's point estimate carries almost nothing. The two part reads (+0.7 ± 9.3 unfitted, +7.8 ± 9.4 for evasion pruning) overstated the whole, as a read adopted just above a threshold does on average.
