## Result / disposition

**Runs (a)–(e) played 2026-09-15, 2,000 games each, 10,000 games in all, one time forfeit (run (d), round 133, the `CoreLmrFullDepth=1` side as White, the same binary on both sides, so the host and not a switch); recomputed from the PGNs by `pgn_result.ps1` (sha256 in the manifests). Printed Elo is defaults against the switch; the switch's effect is its negative.** (a) `CoreRazorGuards=1` printed +2.61 ± 9.89 → effect **−2.6**, between the bounds, default 0 stays; (b) `CoreCorrTrainDecisive=0` printed +15.12 ± 9.73 → effect **−15.1**, **rejected**, default 1 stays; (c) `CoreCorrTrainExcluded=0` printed −2.26 ± 9.53 → effect **+2.3**, between, default 1 stays; (d) `CoreLmrFullDepth=1` printed −1.74 ± 9.93 → effect **+1.7**, between, default 0 stays; (e) `CoreLmrCheckRoot=1` printed +3.82 ± 9.57 → effect **−3.8**, between, default 0 stays. (f) not applicable: no switch reached +5, so nothing is adopted and no defaults commit follows. **Calibration** (predictions written on the 4,706,910 arm; the base was 6,586,667 from the clamp conversion before any game): (a) predicted +8 ± 11, read −2.6: miss in sign, inside the band — the fixed-node tactical loss of 29 canaries is paid for by the node saving, so the screens convicted a trade, not a defect; (b) predicted +3 ± 11, read −15.1: **miss in sign and magnitude, outside the band** — the mechanism read was wrong: mate-range residuals are not noise in the correction, they are the signal that lets the static eval anticipate a forced result, and refusing them costs about 15 Elo; (c) 0 ± 11, read +2.3: held; (d) predicted +5 ± 11, read +1.7: held in band, the interior-node excess against the oracle is not a strength cost at this time control; (e) 0 ± 11, read −3.8: held. **Reading:** five categorical departures from the B.1 head and the donor's shape were each put to games and none beats noise except the one that confirms the donor; the core's structure is settled and the remaining room is in constants (B.2.3) and the later clusters. **Run (g), added by the review 2026-09-15 before it is played:** the clamp conversion changed the tree by 40% (4,706,910 → 6,586,667) without a game, so the arm going to B.2.2.3 is compared once with the arm that measured +52: A = `tools/results/b2221-core-tune-20260915/pext-1.exe` (defaults), B = `tools/test_engines/rarog-b22core-pext-pgo.exe` (sha256 `C51476EB…8313`, bench 4,706,910, the RAR-S73 candidate), same conditions; prediction **0 ± 11** for the converted arm (the clamps limit two LMR terms whose coefficients SPSA refits either way); a reading at or below −5 reverts the conversion and re-registers the clamps as SPSA coordinates instead. **Run (g) played 2026-09-15: converted arm −7.64 ± 9.72 Elo** (nElo −11.98 ± 15.23, 496-964-540, 48.90%, pentanomial [51, 248, 424, 248, 29], one time forfeit on the 4,706,910 side, `sprt_s74-defaults_vs_b22core-4706910_20260915_184909.pgn`). Calibration: predicted 0 ± 11, read −7.6, inside the band; **the pre-registered rule fires at or below −5: the clamp conversion is reverted** (the `b2core` arm returns to 4,706,910 / EBF 2.391 with the five switches inert at their defaults) and the two clamps become four `CoreParams` coordinates seeded at the donor's values (−241, 1155, −65, 91) for B.2.3 to fit. Lesson: a seed-scale correction that moves the tree by 40% is a behaviour change and gets a game before it becomes the base of anything. **Revert commit `308abe9`, 2026-09-15:** `b2core` bench 13 4,706,910 / EBF 2.391, 40/40 per-position lines identical to the pre-conversion arm on magic and PEXT; the four coordinates set to (−110, 528, −30, 42) over UCI reproduce 6,586,667; off arm 7,601,220; B.2.2.2 closed.

## Conditional lesson

Categorical questions answer only in games: the zero-game screens convicted razoring and the review's mechanism read of the mate residuals was wrong; both were cheap to test and both would have misled SPSA had they been assumed. One donor-faithful choice (mate-range residual training) is now measured at about +15 on this evaluation.
