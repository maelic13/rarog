The rule was applied as written in every case. Two limits on the instrument, neither changing a verdict: the bootstrap resamples readings, not builds, so its interval is not the uncertainty of the source change (the same pair read 1.56..1.89 and 0.92..2.56 two hours apart); and the raw readings are not archived, so no interval can be recomputed. A's sign and size rest on three reads over two independent candidate pools (+1.48%, +1.69%, +1.78%) with every candidate build above every base build. I's read began at 11.4% CPU and ended at 21.6%, which AGENTS does not count as idle; both its reads (+0.14% idle, +0.37%) are under the floor, so the revert stands and no rerun is owed.
