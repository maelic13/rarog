# D.7.8.8 — position 305's second divergence from the donor (2026-11-19)

PLAN D.7.8.8, zero games, one session. **The first differing decision is
the pickers' tie rule.** Among equal ordering scores the donor takes the
last entry and removes it with `swap_remove`, and its table move leaves the
generated list the same way; Rarog's pickers take the first and swap it to
the front, and skip the table move as they generate. With the donor's tie
rule alone, `a344748`'s kernel equals the twin on position 305 in nodes and
in every rule count but one (below) through depth 6. The SEE candidates the
PLAN named first (SEE-2, SEE-3) are refuted. **Recorded, not taken:** no
card.

## Steps

1. **SEE.** At depth 3 every SEE variant reads like `a344748`: 956 nodes
   against the twin's 797, 32 of 33 rule kinds differing. Bit 2 alone reads
   837, an artefact (static pins without the king rule let a king take a
   defended piece); with the king rule (6) and with every SEE form (15) it
   is 956. **SEE-2, SEE-3, the king rule and castling are refuted** as the
   cause.
2. **The root.** At depths 1 and 2 the one kind that differs is
   `pick_quiet`, which the donor's root re-scoring inflates. Bit 16 makes it
   equal there, so the re-scoring is reproduced, and leaves depth 3 at 956:
   **refuted as the cause.**
3. **The bisection.** Under node budgets the first difference beyond the
   stop's one asking is hindsight near node 470 (156 askings each, 68
   firings against 67). Hindsight's inputs, printed and set against the
   twin's stride-1 trace, already differ at the third record, node 264, at
   depth 2: the same `eval_delta` values in a different order. The nodes
   are the same; the order they are searched in is not.
4. **The tie rule.** Bit 32: depth 3 797 nodes, depth 4 1,149, depth 5

   `pick_quiet`, whose counts include the twin's root re-scores and its

   changes nothing to depth 6.

## Reading

The divergence D.7.4 left open is not a departure in any rule or in SEE:
it is which of two equally scored moves is searched first. That is the
same sensitivity D.7.8.3 found at the root, where the tie order alone moved
`bench 13` by a third, and the depth-14 column shows it is chaotic, not a
quality: one tie rule runs 305 to 184 million nodes, another to half a
million. **No card.** Matching the donor's tie rule would buy parity on a
diagnostic, not strength, and nothing here says one tie order searches
better than another. The 2.3 times that D.7.4 recorded on 305 is an
instance of that chaos, not a defect.

**For the parity instrument:** a donor-tie mode would let layer B follow
the twin further on a position; it belongs to a later parity read if one is
registered, not to play.
